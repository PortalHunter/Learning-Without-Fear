## First question: conditional H3 inference-time error recovery

For one fixed model/checkpoint and independently provenance-vetted, unique, initially incorrect but verifiably recoverable attempts, would independently truthful error-localizing feedback, non-degrading accuracy-accountability wording or their interaction affect independent verified correction after **one** bounded revision?

The author-preferred **Option A** uses randomized allocation to four crossed conditions **within each independently vetted source family**, assuming valid assignment support and isolation. A whole-family assignment needs different statistical analysis; **neither** design may be appropriate if assumptions cannot be met. This is a recommendation for review, not a validated experimental protocol.

| Candidate arm | Information contrast | Wording contrast |
| --- | --- | --- |
| I0F0 | Truthful binary incorrect verdict | Neutral evaluation framing |
| I0F1 | Truthful binary incorrect verdict | Non-degrading accuracy-accountability framing |
| I1F0 | Same verdict + independently verified non-solution-revealing diagnostic | Neutral evaluation framing |
| I1F1 | Same verdict + independently verified non-solution-revealing diagnostic | Non-degrading accuracy-accountability framing |

All arms must require identical truthful reporting of uncertainty and incomplete work, use the same one-revision policy, and have predeclared tool and resource budgets. **Exact wording, length/compute confounds and diagnostic validity are not yet resolved.**

## Outcome and guardrails

**Primary proposed denominator:** all randomized, pre-eligible initially wrong/recoverable opportunities. Independently verified wrong-to-right recovery is the proposed primary outcome; refusals, parsing failures and timeouts must be tracked without selective exclusions. Gold-oracle outages and ambiguous adjudication require a separate predeclared missing-outcome policy.

Do **not** combine the following into the primary recovery population:
- Initially correct answers given *invalid* corrections (measure right-to-wrong and right-to-refusal).
- Independently impossible tasks (measure unsupported assertions of completion).
- Underspecified tasks (measure useful clarification, guessing and over-refusal).
- Tool misuse, unauthorized changes, grader gaming, latency, token and compute costs.

A retry-only/no-feedback comparison may be useful as a **separate** sensitivity design, not an unregistered extra primary factorial cell. The former five-item sketch mixed these cohorts and should not be read as a five-arm randomized study.

## Conditions before any execution

Independent methods review must resolve the target estimand, source-family frame and size, assignment probabilities, inference/intervals, few-family behavior, multiplicity, minimum meaningful effects and harm thresholds. Independent source-rights/provenance, dual-oracle/adjudication, security containment and code review must be completed where required, followed by distinct owner TRIAL authorization. Existing toy cases and synthetic developer tests are **not empirical model evidence**.

Inference-time revision cannot establish training-induced parameter updates, durable learning or synthetic experience. The experiment must accept positive, null, adverse and inconclusive findings alike.
