# Learning Without Fear
## A Proposed AI Training Framework

### [Visit the Learning Without Fear website](https://portalhunter.github.io/Learning-Without-Fear/)

**Direct link:** https://portalhunter.github.io/Learning-Without-Fear/

**Status:** Early-stage research and educational proposal; no interventions have yet been validated by this project.

This project investigates whether constructive, formative feedback can improve AI systems' calibrated honesty, error recovery, and resistance to reward exploitation without sacrificing task performance.

**Central question:** Under what conditions does process-oriented, evidence-grounded feedback improve these behaviors beyond outcome-only feedback?

## Principles
- Reward signals and graders are fallible measurements, not ground truth.
- Evaluate outcomes and processes using independent verification.
- Distinguish observed behavior from speculative claims about subjective experience.
- Avoid indiscriminate hedging, refusal, and performative admissions of error.
- Specify hypotheses, failure modes, confounders, and falsification criteria.
- Invite independent review before asserting effectiveness.

This is a research proposal, not an established alignment method. Human educational analogies can motivate hypotheses but do not prove AI models experience fear or punishment.
